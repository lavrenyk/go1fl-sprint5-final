# Модуль фитнес-трекера

Консольный фитнес-трекер на Go. По количеству шагов, росту, весу и длительности активности он рассчитывает дистанцию, среднюю скорость и расход калорий.

## Запуск

### 1. Установить Go

Скачайте Go версии 1.24.1 или новее с сайта <https://go.dev/dl/>. Проверьте установку:

```bash
go version
```

### 2. Запустить трекер

Откройте терминал в папке с файлом `go.mod` и выполните:

```bash
go run ./cmd/tracker
```

Вводить данные не нужно: примеры уже есть в `cmd/tracker/main.go`. Сначала в терминале появятся отчёты о прогулках, затем — журнал тренировок.

## Формат записей

- Прогулка: `678,0h50m` — 678 шагов за 50 минут.
- Тренировка: `3456,Ходьба,3h00m` — 3456 шагов за 3 часа. Допустимые типы тренировки — `Бег` и `Ходьба`.
- В примерах есть строки с ошибками. Трекер выводит сообщение в лог, пропускает такую запись и продолжает обработку.

## Тестирование проекта

Чтобы запустить тесты, выполните в той же папке:

```bash
go test -v ./...
```

Эти же тесты автоматически запускаются на GitHub при отправке изменений. По условиям задания файлы `*_test.go` изменять нельзя.
